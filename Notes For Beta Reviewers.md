# Notes for beta testers
## MACS GUIDE Version 0.1.0 - 13/09/2026

### Context
This repo contains the beta version of the guide for Mahzel’s MACS application. You have volunteered to be a document beta tester. Firstly can I thank you for taking the time to help with this project.

Please do not circulate this document to others not involved as there is still much work to do and it would not be helpful to have various versions circulating before Mahzel is ready.

### Key areas to address
It is assumed that the user base for MACS will be very broad so from a technical point of view much of the document may seem simplistic. There are more technical sections but the focus has been on showing how MACS can be integrated into MNW from a game players perspective.

Some key areas to consider:
- Basic typos, spelling and grammar
- Narrative flow. Does it read well?
- Does it answer questions a new user might have
- Is it technically competent
- Do links work
- Is there anything missing
- Do the graphics help or hinder

Anything else you think is relevant.

### Try it yourself
One of our visions is for there to be several interactive examples with this document. As it stands there is one example ready based on @snrkatat’s Type 55 exercise. Download the sound file and load it into MACS and try to recreate the process outlined in the Ex1 Illustrated Examples Section. As new exercises are developed they will posted here for you to look at before being incorporated in Version 0.2.0.
